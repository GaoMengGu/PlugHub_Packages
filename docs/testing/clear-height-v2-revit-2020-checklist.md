# 净高分析 V2 — Revit 2020 实机检查清单

## 测试前准备

- 使用 Revit 2020.2，加载本分支 Release 构建的 `PlugHub.ClearHeightAnalysis.dll`。
- 准备含凹形楼板、洞口、结构梁柱、吊顶、风管、桥架、管道的项目。
- 放置同一链接模型的两个实例，其中一个旋转 30–45°，另一个镜像；保留实例名称和位置截图。
- 面积成果测试模板预置面积方案 `PH_净高分析` 和视图模板 `PH_净高分析_色块`；另存一份缺少这两个资产的项目。

## 分析上下文与几何

- [ ] 楼层下拉框仅列出真实 Level，不能手填标高。
- [ ] 分别测试选择宿主楼板、选择链接楼板、自动当前楼层楼板、裁剪矩形和手动矩形。
- [ ] 凹边界外部不生成网格；楼板洞口内不生成网格；不连续楼板均参与分析。
- [ ] 旋转和镜像链接中的构件落在正确宿主坐标；同一链接文件的两个实例结果键不同。
- [ ] 取消选择、取消拾取或关闭窗口时，不产生批次或 Revit 成果图元。

## 障碍物与计算

- [ ] 梁、上层楼板、吊顶、风管、桥架和管道按最低底标高控制净高。
- [ ] 当前完成面以下的本层楼板不被当成顶部障碍物。
- [ ] 穿过通行空间的结构柱显示为“不可通行”。
- [ ] 小于最小管径的管道被排除；大于阈值的管道参与计算。
- [ ] 没有顶部障碍物的网格显示“未判断”，不自动判为达标。
- [ ] 包围盒回退与类别近似结果在结果窗口显示“近似结果提醒”。

## 批次持久化

- [ ] 分析完成后先出现可重新打开的批次，再允许生成任何成果。
- [ ] 保存、关闭并重新打开项目后，历史批次的网格、控制构件、筛选和汇总一致。
- [ ] 删除某一派生成果后，批次仍可读取并能重新生成成果。
- [ ] 删除批次前出现确认；确认后只删除该批次数据和其带标签的 Revit 成果。
- [ ] 用测试副本破坏或移除一个批次 DataStorage 分块；结果管理应标为损坏、禁止导出、仍允许删除。

## 默认轻量成果

- [ ] 当前平面视图生成问题区域闭合详图线和一个区域编号文字，不创建 FilledRegion。
- [ ] 相邻同等级网格合并，内部公共边不出现；环形问题区域保留洞口。
- [ ] 严重不足、不足、临界、未判断、不可通行使用不同线样式，文字同时给出状态/净高信息。
- [ ] 放大、打印和导出 PDF 后轮廓与文字可读；模型规模较大时视图操作无明显逐格填充卡顿。
- [ ] 重新生成只替换当前批次同类成果，不删除用户详图线或其他批次成果。

## 可选面积色块

- [ ] 缺少 `PH_净高分析` 时明确拒绝，且项目原有面积方案、面积平面和面积均不变化。
- [ ] 有面积方案但缺少 `PH_净高分析_色块` 时显示警告，可生成面积数据但不宣称已有配色。
- [ ] 生成前显示预计面积数和边界线数；逐格模式数量大时强提醒，不静默截断。
- [ ] 合并模式面积名称稳定匹配等级；逐格模式仅在小范围使用。
- [ ] 删除面积成果只删除插件创建的面积平面、边界和面积，不删除面积方案或用户面积。

## PNG 与 CSV

- [ ] PNG 成果在一个视图中只创建一个 ImageType 和一个 ImageInstance，位置和宽高覆盖分析范围。
- [ ] PNG 文件删除后可从同一批次重新生成；重新导入后比例和背景层正确。
- [ ] CSV 使用 UTF-8 BOM，行数等于全部有效网格数加表头，包含状态、可信度、控制构件、类别、来源模型和链接实例键。
- [ ] CSV/PNG 外部文件在删除 Revit 成果或批次时不会被无提示删除。
