# 净高分析 V2 重构设计

## 1. 文档定位

本文档定义 `PlugHub.ClearHeightAnalysis` 的第二版设计，并取代 2026-06-17 设计中以逐格 `FilledRegion` 热力图为主要成果的实现方向。旧文档保留用于追溯，不再作为后续实现依据。

允许重构现有模块内部结构，不要求兼容旧版服务类和数据模型。模块 ID、功能 ID、命令类型和现有包入口保持稳定，避免破坏 PlugHub 的模块发现与升级路径。

## 2. 设计结论

第二版采用“计算数据与成果载体分离”的架构：

1. 净高分析批次是唯一数据源，完整保留分析范围、参数、网格结果和控制构件信息。
2. 默认生成轻量矢量成果，不再逐格创建面填充图元。
3. 面积色块图是用户主动选择的派生成果，默认合并相邻同等级网格。
4. PNG 热力图是大范围彩色总览的另一种可选成果，一个视图只维护一个图像实例。
5. 删除或重新生成任何一种成果，不影响原始净高分析数据。
6. 重构计算核心，解决旧版矩形范围、旋转链接、全量扫描和类别语义混用问题。

## 3. 目标

- 从真实 `Level` 和真实分析边界建立分析上下文，不再要求用户手填楼层标高。
- 支持当前模型及用户选择的链接实例，并正确处理平移、旋转和镜像变换。
- 对结构、建筑和机电障碍物进行分层粗筛与分类精筛。
- 避免 `网格数 × 全部障碍物数` 的全量循环。
- 保留每格最不利净高、风险等级、控制构件和计算可信度。
- 默认输出问题区域轮廓、编号标记和结果表。
- 可从同一分析批次生成面积色块图、PNG 热力图和 CSV。
- 支持按批次更新和清理成果，绝不清理用户创建的同类图元。
- 在 Revit 2020 中可编译、可运行、可打印并可回溯结果来源。

## 4. 非目标

- 不做结构力学分析。
- 不替代碰撞检查工具。
- 不在第一阶段支持全部异形族的精确实体布尔运算。
- 不自动修改项目已有的建筑面积、租赁面积或商业面积方案。
- 不保证在 Revit 2020 API 中从零创建面积方案或完整配置颜色填充方案。
- 不在模型打开、视图切换或模型变化时自动重新分析。
- 不在第一阶段做全项目全部楼层的一键无人值守批处理。

## 5. 备选方案与选择

### 5.1 在旧版上补丁修复

保留矩形范围、BoundingBox 投影和逐格 `FilledRegion`，只增加更多数量上限和局部优化。改动小，但不能根治准确性、链接变换和 Revit 面填充卡顿问题，不采用。

### 5.2 数据驱动的分层计算与多成果输出

重构分析核心，完整结果保存为独立批次；默认生成轻量矢量成果，面积色块和 PNG 作为可选输出。开发量中等，但准确性、性能和交付灵活性最均衡，采用本方案。

### 5.3 仅使用临时图形或外部查看器

使用 AVF、DirectContext3D 或外部网页查看全部结果。交互性能较好，但打印、持久化和正式交付不稳定，不作为主方案。后续可以增加 DirectContext3D 作为瞬时预览，但不得成为唯一成果。

## 6. 总体架构

```text
Revit 模型
  -> AnalysisContextBuilder
  -> AnalysisBoundaryProvider
  -> ObstacleSnapshotCollector
  -> GridDomainBuilder
  -> ObstacleSpatialIndex
  -> ClearHeightAnalysisEngine
  -> AnalysisBatchRepository
       -> LightweightDrawingExporter
       -> AreaColorPlanExporter
       -> RasterHeatmapExporter
       -> CsvExporter
```

Revit API 读取和写入必须在 Revit 主线程执行。几何快照转换为不持有 Revit API 对象的纯数据后，空间索引、网格计算、风险区域合并、序列化和 PNG 生成可以在后台线程执行。

## 7. 用户流程

### 7.1 新建分析

1. 用户打开 `净高分析`。
2. 用户从真实楼层列表选择一个 `Level`。
3. 用户选择分析范围来源：
   - 选择当前模型楼板；
   - 选择链接模型楼板；
   - 自动识别当前楼层建筑楼板；
   - 当前平面视图裁剪范围；
   - 手动矩形范围。
4. 用户选择参与分析的当前模型和具体链接实例。
5. 用户设置网格、阈值、完成面偏移、搜索高度、类别和最小管径。
6. 插件显示预估范围、网格数、候选模型和输出模式。
7. 用户开始分析，可查看阶段进度并取消。
8. 计算成功后先保存分析批次，再打开结果窗口。
9. 用户按需生成轻量成果、面积色块图、PNG 或 CSV。

### 7.2 打开历史批次

结果管理窗口列出楼层、时间、阈值、网格尺寸、问题数量和已有成果。用户可以打开、导出、重新生成成果或删除批次。历史批次默认只读；模型变化后如需最新结果，应创建新批次。

### 7.3 清理

- `删除派生成果`：删除选定批次的详图线、标记、面积成果或图片，保留分析数据。
- `删除分析批次`：先确认，再删除批次数据及其全部派生成果。
- `清理旧版热力图`：兼容识别旧版 Extensible Storage 标签，只删除旧插件生成的 `FilledRegion`。

## 8. 分析上下文

`AnalysisContext` 必须保存：

- 宿主文档标识和标题；
- `Level.UniqueId`、名称和标高；
- 完成面标高；
- 搜索高度；
- 当前视图 ID 和类型；
- 被选中的链接实例 ID、UniqueId、文档标题和总变换；
- 分析参数；
- 分析开始时间。

楼层下拉框只能返回当前文档中的真实 `Level`。面积平面、三维视图和没有关联楼层的视图不能通过文本推断楼层。

## 9. 分析范围

### 9.1 边界数据模型

`AnalysisBoundary` 由一个或多个平面区域组成。每个区域包含一个外环和零个或多个洞口。坐标统一转换到宿主模型坐标系，长度在 Revit API 边界层使用英尺，进入纯计算层后统一使用毫米。

### 9.2 楼板边界

选择楼板时，从楼板顶面或可用的水平几何面提取真实边界环，不使用元素 BoundingBox 代替轮廓。链接楼板的全部边界点通过链接实例总变换转换到宿主坐标。

自动识别只收集与所选楼层标高相符的当前模型建筑楼板，不收集搜索高度内的上层楼板。自动结果存在多个不连续楼板时保留为多个区域。

### 9.3 裁剪和手动范围

当前视图裁剪范围与手动框选是明确的矩形兜底。界面必须标注“矩形分析范围”，不能将其描述为自动识别建筑外轮廓。

### 9.4 网格域

网格按分析边界的统一原点生成。每个 `GridCell` 同时保存矩形范围和与分析边界相交后的有效区域。洞口和边界外部分不参与计算，也不参与输出。边界相交采用整数毫米坐标的多边形裁剪，避免浮点误差导致细缝和重复边。

## 10. 障碍物快照

### 10.1 来源与唯一标识

障碍物键必须包含来源实例：

```text
host:{elementUniqueId}
link:{linkInstanceUniqueId}:{linkedElementUniqueId}
```

不能只使用链接文档内的 ElementId，因为同一链接模型可能被放置多次。

### 10.2 坐标变换

所有链接几何使用 `RevitLinkInstance.GetTotalTransform()` 转换。任何包围盒变换都必须转换 8 个角点后重新求宿主坐标包围盒，禁止只转换 `Min` 和 `Max`。

元素自身的 `BoundingBoxXYZ.Transform` 也必须与链接变换组合处理。镜像链接必须通过实际点变换处理，不能假设坐标轴方向不变。

### 10.3 类别语义

障碍物分为：

- `Overhead`：楼板、梁、吊顶、风管、桥架、管道及其附件，参与净高计算；
- `Blocked`：结构柱等从完成面穿过通行空间的构件，标记为不可通行；
- `Ignored`：低于完成面、超出搜索高度、被类别设置排除或小于过滤尺寸的构件。

最小管径必须真正用于管道和圆形附件过滤。风管和桥架后续可增加各自的最小尺寸过滤，但不复用管径参数。

### 10.4 几何表达

采用分类快照，不把所有构件退化成一个轴对齐矩形：

- 水平楼板和吊顶：底面边界与底标高；
- 直线梁、风管、桥架和管道：中心线、截面尺寸、方向和端部底标高；
- 斜向线性构件：保存两端底标高，在覆盖区间内计算局部最低值；
- 管件、附件和复杂族：保存变换后的实体投影；实体不可用时使用 8 点包围盒作为保守近似；
- 结构柱：保存有效占地区域和垂直范围。

每个快照标记 `Exact`、`CategoryApproximation` 或 `BoundingBoxFallback` 可信度。结果表必须能显示近似计算，避免把保守结果伪装成精确结果。

## 11. 候选筛选与空间索引

### 11.1 Revit 侧粗筛

对当前文档和每个链接文档分别建立分析范围的三维查询盒。查询盒转换到对应文档坐标后，组合类别过滤、元素类型过滤和包围盒过滤，避免读取整个链接模型的全部目标类别。

### 11.2 纯计算侧索引

`ObstacleSpatialIndex` 按分析网格坐标建立桶索引。每个障碍物只登记到其投影覆盖的网格索引范围。计算单元格时只读取本格桶内的候选障碍物。

禁止在主路径中对每个网格重新遍历完整障碍物集合。

## 12. 净高计算

每个有效网格的分析基准为：

```text
完成面标高 = Level 标高 + 完成面偏移
净高 = 覆盖有效区域的最低顶部障碍底标高 - 完成面标高
```

计算规则：

1. 先判断网格有效区域是否被 `Blocked` 障碍物占用；占用时结果为 `Blocked`。
2. 对候选 `Overhead` 障碍物做投影重叠精筛。仅碰到轴对齐包围盒但不碰到实际投影的构件不应控制该格。
3. 对每个实际覆盖构件计算其在网格有效区域内的最低底标高。
4. 取所有覆盖构件的最小值作为控制净高。
5. 无顶部障碍物时标记 `Unknown`，不自动判为达标。
6. 完成面以下或只接触容差带的本层楼板不作为顶部障碍。

风险等级：

- `Severe`：净高小于阈值减 300mm；
- `Insufficient`：净高小于阈值；
- `Warning`：净高小于阈值加 300mm；
- `Passed`：净高大于或等于阈值加 300mm；
- `Unknown`：缺少可判断的顶部障碍；
- `Blocked`：有效通行区域被竖向实体占用。

300mm 分级带在 V2 第一阶段保持为固定产品规则；后续如需配置，应通过独立版本变更处理。

## 13. 分析批次与持久化

### 13.1 批次内容

`AnalysisBatch` 保存：

- Schema 版本；
- 批次 ID；
- 分析上下文与参数；
- 分析边界；
- 每格有效区域、净高、等级和可信度；
- 控制构件键、名称、类别和来源；
- 汇总统计；
- 派生成果清单。

### 13.2 Revit 存储

使用 `DataStorage + Extensible Storage`。一个元数据 `DataStorage` 保存批次索引和摘要；网格结果序列化为 JSON，使用 GZip 压缩并转为 Base64，再按不超过 256KiB 的字符串块写入多个带批次 ID 和序号的 `DataStorage`。元数据保存块数、未压缩长度和 SHA-256 校验值。

读取时必须验证版本、块连续性、长度和校验值。校验失败的批次显示为损坏，不允许基于其生成成果，但允许安全删除。

Schema 只新增不修改。未来格式变化通过新的 Schema GUID 和显式迁移器处理。

### 13.3 更新策略

分析批次创建后不自动随模型变化更新。结果窗口显示分析时间和来源模型。用户重新分析时创建新批次，并选择保留、归档或删除旧批次。

## 14. 默认轻量成果

### 14.1 风险区域合并

按风险等级对网格做四邻域连通分组。每个连通分组消除内部公共边，保留外环和洞口，合并共线线段，并按固定毫米容差简化锯齿边界。

默认只输出 `Severe`、`Insufficient`、`Warning`、`Unknown` 和 `Blocked`，不输出 `Passed`。

### 14.2 Revit 图元

每个风险区域创建少量闭合详图线，不创建填充区域。线样式按等级区分。每个区域放置一个编号标记，标记位置使用区域内部点，不直接使用可能落在区域外的多边形质心。

标记显示区域编号和最低净高；控制构件、来源模型和完整网格列表在结果窗口中查看。

所有图元写入批次 ID、成果类型和区域 ID 标签。清理只能通过这些标签定位插件成果。

## 15. 可选面积色块图

### 15.1 前置条件

Revit 2020 可以创建面积平面、面积边界和面积，但不能可靠地通过公开 API 从零创建面积方案并完整配置颜色填充方案。项目模板应预置：

- 面积方案 `PH_净高分析`；
- 基于面积名称的颜色填充规则；
- 已应用上述颜色规则的面积视图模板 `PH_净高分析_色块`；
- 可选的 PlugHub 净高共享参数。

面积方案缺失时，插件不得修改项目现有面积方案。应提示用户加载 PlugHub 模板，或由用户明确选择一个现有面积方案并确认风险。面积视图模板存在时，插件将其应用到新建面积平面；模板缺失时仍可生成面积与数据，但必须明确提示用户需要手动配置颜色方案，不能宣称已经生成完整色块图。

### 15.2 生成模式

提供两种模式：

- `风险区域合并`：默认。相邻同等级网格合并为一个面积，区域最低净高取所有成员格的最小值。
- `逐格面积`：高级选项。一个有效网格对应一个面积，仅适用于局部范围。

生成前必须显示预计面积数和边界线数。超过安全阈值时强提醒，用户可以返回改用合并模式或 PNG；不得静默截断。

### 15.3 面积数据

面积 `Number` 使用批次内唯一编号，`Name` 使用稳定的中文等级名称以驱动模板颜色规则。完整数据仍来自 `AnalysisBatch`。

若项目已存在 PlugHub 共享参数，则写入批次 ID、区域编号、最低净高、阈值、差值、网格数、控制构件和来源模型；若参数缺失，则仅写入 `Name`、`Number` 和 Extensible Storage 标签，并提示颜色图可用但原生面积明细字段受限。

### 15.4 边界与清理

面积边界从合并区域边缘生成，共线边合并，相同公共边只创建一次。面积放置点必须是对应闭合区域的内部点。

插件记录自己创建的面积平面、面积、边界线和标签。删除面积成果只删除指定批次的这些图元，不删除面积方案、用户面积或其他楼层成果。

## 16. 可选 PNG 热力图

`RasterHeatmapExporter` 在内存中按批次网格生成透明背景 PNG，可选择输出全部等级或只输出问题区域，并附图例和分析摘要。

导入 Revit 时一个成果对应一个 `ImageType` 和一个 `ImageInstance`，按分析边界定位和缩放。图片默认置于底层并锁定比例。批次记录图片文件路径、图像类型 ID 和实例 ID。

图片文件丢失时，插件可从批次数据重新生成。PNG 是彩色总览，不承担网格级数据追溯。

## 17. 结果窗口与成果管理

结果窗口必须支持：

- 按等级、可信度、来源模型和构件类别筛选；
- 查看每个风险区域和成员网格；
- 查看控制构件及链接实例；
- 选中宿主构件，或打开链接实例与链接构件定位提示；
- 生成、重新生成和删除各类派生成果；
- 导出 CSV；
- 显示分析时间、参数和近似结果警告。

不再只显示一个无法追溯截断规则的结果列表。任何成果数量限制都必须在生成前展示并由用户选择处理方式。

## 18. 运行阶段与取消

分析分为以下阶段：

1. 读取分析上下文和边界；
2. 收集 Revit 障碍物快照；
3. 建立网格和空间索引；
4. 计算净高；
5. 合并风险区域；
6. 保存批次；
7. 按用户选择生成成果。

阶段 1、2、6、7 在 Revit 主线程执行。阶段 3、4、5 使用纯数据计算，可以在后台线程执行。进度窗口提供取消操作。取消发生在保存批次前时不写入任何成果；成果生成阶段取消或失败时回滚对应输出事务，但保留已经成功保存的分析批次。

## 19. 事务边界

- 分析读取不启动事务。
- 保存批次使用一个短事务。
- 每种派生成果使用独立事务组。
- 面积平面、边界和面积在同一事务组中分步骤创建；任一步失败时回滚本次面积成果。
- 删除成果和删除批次分别使用独立事务。

不能用一个长事务包住模型读取、纯计算、UI 等待和全部成果生成。

## 20. 错误处理

- 没有有效楼层：阻止分析并提示选择真实楼层。
- 链接未加载：显示不可用，不静默忽略用户已选链接。
- 链接变换异常或几何读取失败：记录来源并将受影响结果标为近似或未知。
- 无法识别楼板边界：允许改用视图裁剪或手动矩形。
- 网格量过大：在计算前显示估算并允许调整网格或范围。
- 面积方案缺失：不自动污染现有面积方案，提示模板前置条件。
- 当前视图不支持目标成果：允许选择或创建适合的平面视图。
- DataStorage 校验失败：禁止导出损坏批次，允许删除。
- 成果创建失败：回滚该成果事务，保留分析批次和其他已经完成的成果。

## 21. 组件边界

- `ClearHeightAnalysisCommand`：命令入口，只启动工作流控制器。
- `AnalysisWorkflowController`：阶段调度、进度、取消和事务协调。
- `AnalysisContextBuilder`：楼层、链接实例和参数验证。
- `AnalysisBoundaryProvider`：真实楼板边界和矩形兜底。
- `ObstacleSnapshotCollector`：Revit 过滤、几何提取和坐标转换。
- `GridDomainBuilder`：网格及有效区域生成。
- `ObstacleSpatialIndex`：网格桶索引。
- `ClearHeightAnalysisEngine`：纯净高计算。
- `RiskRegionBuilder`：连通区域和矢量边界。
- `AnalysisBatchRepository`：批次序列化、校验、读取和删除。
- `LightweightDrawingExporter`：详图线和编号标记。
- `AreaColorPlanExporter`：可选面积平面成果。
- `RasterHeatmapExporter`：PNG 生成、导入和重载。
- `CsvExporter`：完整网格与区域摘要导出。
- `AnalysisResultWindow`：结果浏览和成果管理。
- `LegacyResultCleanupService`：旧版 FilledRegion 清理兼容。

服务之间通过纯模型和小接口通信。Revit API 类型不能进入纯计算核心，ElementId 只允许作为来源元数据存在。

## 22. 旧版迁移

- 保留模块和功能标识。
- 删除旧版逐格 `HeatmapRenderer` 主路径和 500 格静默截断逻辑。
- 旧版没有独立批次数据，不能迁移为完整 V2 批次。
- 首次运行 V2 时检测旧版标签，提示用户清理旧热力图。
- 可复用风险分类、单位转换和结果表视觉样式，但必须通过新接口接入。

## 24. 验收标准

- 默认分析不创建 `FilledRegion`、面积或 DirectShape 面。
- 真实楼板范围保留凹形边界、洞口和不连续区域。
- 旋转、镜像和重复放置链接实例能得到不同且正确的宿主坐标结果。
- 主计算路径使用空间索引，不对每格扫描完整障碍物集合。
- 只穿过网格边缘的梁和机电构件能控制该格。
- 当前楼板不会产生零或负净高假结果，结构柱显示为不可通行。
- 删除轻量、面积或 PNG 成果后，可以从保存的批次重新生成。
- 面积色块生成是显式可选操作，默认使用风险区域合并模式。
- 面积方案缺失时不修改项目现有面积体系。
- 任何数量限制都在生成前告知用户，不静默丢弃结果。
- 单元测试、包校验和 Release/NuGet 模式构建通过。
- 完成 Revit 2020 运行时清单后才能发布为生产版本。

2. 批次持久化、结果管理和轻量成果；
3. 面积色块成果；
4. PNG、CSV、旧版清理和完整 Revit 运行时验证。
