# 湖北报规模板执行器设计

## 目标

湖北报规插件只执行用户在界面选择的 CSV 模板：创建或更新 Revit 共享参数、按模板写入值，并在已保存项目所在目录输出 `项目名-HIFC.txt`。插件不再读取内置 HIFC、mini 或按分类推导参数。

## 模板契约

模板为 UTF-8 BOM CSV，表头固定且顺序固定：

`属性集名称,参数类型,IFC构件,Revit类别,属性名称,IFC属性类型,Revit参数类型,默认值,真实数据`

`参数类型` 必须为 `I` 或 `T`，决定实例或类型绑定。`Revit类别` 使用受支持的中文类别名称，多个类别以逗号分隔并按 CSV 规则引用。`IFC属性类型` 使用 IFC Exporter 的数据类型；`Revit参数类型` 是目标 Revit 版本的 `ParameterType` 枚举名称，只用于共享参数创建。

## 执行语义

插件先解析并验证整个模板，再显示同名参数合并清单。相同实际 Revit 参数名称且 `I/T` 与 `Revit参数类型` 相同的行合并 Revit 绑定类别。每个原始模板行独立赋值：真实数据非空时使用真实数据，否则使用默认值。不同属性集或不同 Revit 类别中的同名参数允许值不同；同名参数写入同一个 Revit 类别而最终值不同，则对冲突组中的每一行将实际 Revit 参数名改为 `属性集名称_属性名称`，以独立创建、绑定和赋值；原 IFC 属性名称保持不变。别名碰撞且 `I/T` 或 `Revit参数类型` 不一致时阻止执行。

真实数据非空时覆盖模板目标参数的现有值；真实数据为空时覆盖为默认值。唯一执行选项为“清除当前项目同名参数”：勾选时先移除同名绑定再创建，未勾选时仅复用兼容定义或补齐类别，定义冲突时阻止执行。

项目必须已保存。输出文件固定为 `<项目目录>/<项目文件名>-HIFC.txt`，其中属性行的第二列来自 `IFC属性类型`，第三列为解析后的实际 Revit 参数名。

## 边界

Revit 中文类别目录集中维护，覆盖建筑、结构、暖通、给排水和电气常用类别，模板中未知类别按行号报错。旧的 HIFC/mini 嵌入资源、分类选择、默认值输入、IFC 到 Revit 类别推导和名称猜测全部移除。
