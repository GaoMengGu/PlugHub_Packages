# 湖北报规模板执行器设计

## 目标

湖北报规插件只执行用户在界面选择的 CSV 模板：创建或更新 Revit 共享参数、按模板写入值，并在已保存项目所在目录输出 `项目名-HIFC.txt`。插件不再读取内置 HIFC、mini 或按分类推导参数。

## 模板契约

模板为 UTF-8 BOM CSV，表头固定且顺序固定：

`属性集名称,参数类型,IFC构件,Revit构件,属性名称,属性类型,默认值,真实数据`

`参数类型` 必须为 `I` 或 `T`，决定实例或类型绑定。`Revit构件` 使用受支持的中文类别名称，多个类别以逗号分隔并按 CSV 规则引用。`属性类型` 是目标 Revit 版本的 `ParameterType` 枚举名称，直接用于 HIFC 输出及共享参数创建。

## 执行语义

插件先解析并验证整个模板，再显示同名参数合并清单。相同参数名称的兼容行合并 Revit 绑定类别；参数类型、属性类型、默认值或真实数据不一致则阻止执行。

真实数据非空时覆盖模板目标参数的现有值；真实数据为空时覆盖为默认值。唯一执行选项为“清除当前项目同名参数”：勾选时先移除同名绑定再创建，未勾选时仅复用兼容定义或补齐类别，定义冲突时阻止执行。

项目必须已保存。输出文件固定为 `<项目目录>/<项目文件名>-HIFC.txt`，其中的属性集信息仅来自 `属性集名称、参数类型、IFC构件、属性名称、属性类型`。

## 边界

Revit 中文类别目录集中维护，覆盖建筑、结构、暖通、给排水和电气常用类别，模板中未知类别按行号报错。旧的 HIFC/mini 嵌入资源、分类选择、默认值输入、IFC 到 Revit 类别推导和名称猜测全部移除。
